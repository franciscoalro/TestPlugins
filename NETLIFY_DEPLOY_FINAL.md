# 🚀 Deploy no Netlify - Guia Final

## ✅ Arquivos Prontos!

Você tem **2 opções** para fazer upload:
- 📁 **Pasta**: `cloud-deploy` (1.91 MB)
- 📦 **ZIP**: `brcloudstream-netlify.zip` (1.82 MB)

## 🌐 Como Fazer Deploy

### Passo 1: Acessar Netlify
1. Abra seu navegador
2. Vá para: **https://netlify.com**
3. Clique em **"Sign up"** (criar conta) ou **"Log in"** (entrar)

### Passo 2: Criar Conta (se necessário)
- Use **GitHub**, **Google** ou **email**
- É **100% gratuito**

### Passo 3: Deploy
1. Na dashboard do Netlify, procure por:
   **"Want to deploy a new site without connecting to Git?"**
2. Clique em **"Browse to upload"**
3. **ARRASTE** a pasta `cloud-deploy` OU o arquivo `brcloudstream-netlify.zip`
4. **Aguarde** o upload (alguns minutos)

### Passo 4: Obter URL
1. Após o deploy, você receberá uma URL como:
   ```
   https://nome-aleatorio-123456.netlify.app
   ```
2. **Anote esta URL!**

### Passo 5: Personalizar Nome (Opcional)
1. Clique em **"Site settings"**
2. Clique em **"Change site name"**
3. Escolha um nome como: `brcloudstream-repo`
4. Sua URL ficará: `https://brcloudstream-repo.netlify.app`

## 🎯 URL Final para Cloudstream

Sua URL final será:
```
https://SEU-NOME.netlify.app/repo.json
```

## ✅ Teste Após Deploy

Abra no navegador e teste:
- ✅ `https://SEU-SITE.netlify.app/repo.json` (deve mostrar JSON)
- ✅ `https://SEU-SITE.netlify.app/plugins.json` (lista de plugins)
- ✅ `https://SEU-SITE.netlify.app` (página bonita com informações)

## 📱 Usar no Cloudstream

1. **Abra o Cloudstream** no Android
2. **Configurações** → **Extensões**
3. **Adicionar Repositório**
4. **Cole sua URL**: `https://SEU-SITE.netlify.app/repo.json`
5. **Instale os plugins!**

## 🔄 Atualizações Futuras

Para atualizar os plugins:
1. Modifique os arquivos na pasta `cloud-deploy`
2. Arraste novamente para o Netlify
3. Deploy automático!

## 🆘 Se Algo Der Errado

### Erro de Upload:
- Tente usar o ZIP em vez da pasta
- Verifique sua conexão de internet

### URL não funciona:
- Aguarde alguns minutos (propagação DNS)
- Teste com `https://` (não `http://`)

### Cloudstream não baixa:
- Verifique se a URL termina com `/repo.json`
- Teste a URL no navegador primeiro
