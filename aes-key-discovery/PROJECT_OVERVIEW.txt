┌────────────────────────────────────────────────────────────────────────────────┐
│                        🔑 FÓRMULAS CANDIDATAS                                  │
└────────────────────────────────────────────────────────────────────────────────┘

Baseado em análises anteriores, as fórmulas mais prováveis são:

  1. MD5(user_id + slug + md5_id)
  2. MD5(slug + user_id + md5_id)
  3. MD5(md5_id + user_id + slug)
  4. MD5(user_id + ":" + slug + ":" + md5_id)
  5. SHA256(user_id + slug + md5_id)
  6. user_id + slug + md5_id (sem hash)

Os scripts testam automaticamente todas essas combinações!
