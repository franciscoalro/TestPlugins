1. Abrir WSL:
   wsl

2. Navegar:
   cd /mnt/c/caminho/para/aes-key-discovery

3. Dar permissões:
   chmod +x *.sh scripts/*.sh

4. Executar teste rápido:
   bash quick_test.sh

5. OU análise completa:
   bash run_analysis.sh

└────────────────────────────────────────────────────────────────┘

Parâmetros conhecidos:
  user_id = "482120"
  slug    = "kBJLtxCD3"
  md5_id  = "28930647"

Possíveis fórmulas:
  ✓ user_id + slug + md5_id
  ✓ MD5(user_id + slug + md5_id)
  ✓ MD5(slug + user_id + md5_id)
  ✓ MD5(md5_id + user_id + slug)
  ✓ SHA256(...)
  ✓ Com separadores: ":" ou "-"
