┌────────────────────────────────────────────────────────────────────────────────┐
│                        🎯 O QUE ESTE PROJETO FAZ?                              │
└────────────────────────────────────────────────────────────────────────────────┘

O PlayerEmbedAPI retorna dados criptografados:

  {
    "user_id": "482120",
    "slug": "kBJLtxCD3",
    "md5_id": "28930647",
    "media": "U2FsdGVkX1..." ← Criptografado com AES
  }

Este projeto descobre automaticamente a fórmula usada para gerar a chave AES
que decripta o campo "media".

Possíveis fórmulas:
  • MD5(user_id + slug + md5_id)
  • MD5(slug + user_id + md5_id)
  • SHA256(...)
  • E outras combinações
