# BRCloudStream Repository

Repositório brasileiro de plugins para CloudStream

## URL para adicionar ao CloudStream

```
https://raw.githubusercontent.com/franciscoalro/CloudstreamRepo/main/plugins.json
```

## Como adicionar

1. Abra o CloudStream
2. Vá em Configurações → Extensões
3. Toque em "Adicionar Repositório"
4. Cole a URL acima
5. Toque em OK
